# Divider

Render a GOV.UK Design System styled divider used to separate sections of content.

## How it works

- Renders a `<div class="govuk-checkboxes__divider">` or `<div class="govuk-radios__divider">` element.
- `Text` optional parameter to set the text shown in the divider. If no `Text` is provided, "or" is used as the default text.

## Variants

All divider components work the same way, but are used to divide different content, with different CSS classes applied.

The following components are available:
- GdsCheckboxDivider - see [GdsCheckboxes](Checkboxes.md)
- GdsRadioDivider - see [GdsRadios](Radios.md)
