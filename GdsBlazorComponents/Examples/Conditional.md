# Conditional

Render a GOV.UK Design System styled element for conditional content.

## How it works

- Renders a `<div class="govuk-checkboxes__conditional">` or `<div class="govuk-radios__conditional">` element.
- `Id` required parameter, sets the `id` attribute of the element.

The `Id` parameter should match the `ConditionalId` parameter of `GdsInputCheckbox` or `GdsInputRadio`.

## Variants

The following components are available:
- GdsCheckboxConditional - see [GdsCheckboxes](Checkboxes.md)
- GdsRadioConditional - see [GdsRadios](Radios.md)
